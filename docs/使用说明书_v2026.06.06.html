一、系统概览

组成

程序用途部署
SwimmingScoreboard.exe主控 — 赛事管理、计时、显示推送主控 PC（1 台）
RemoteTimingControl.exe远程计时台 — 与主控同步, 显示道次实时计时席（按需）
RemoteDisplayControl.exe远程显示控制 — 主控大屏切换的备份裁判席（按需）
RegistrationTool.exe报名工具 — 远程录入运动员/接力报名席（按需）
ScheduleEditor.exe赛程编辑器 — 离线规划赛程办公席（按需）
display.html观众大屏 — 浏览器渲染LED 显示墙
race_control.html计时控制 网页端 — 浏览器操作裁判席手机/平板
control.html大屏控制 网页端 — 切视图 + 样式主控席手机/平板

4 端联动

主控 PC + RemoteTimingControl.exe + race_control.html + display.html 通过 WebSocket (端口 3002) 实时同步。主控是唯一的数据源 — 名次/分段/反应时/破纪录/滚动时间都由主控计算后广播，其它 3 端只渲染。

数据流原则：大屏与文档数据来自主控，前端不重算、不缓存比赛数据。这避免了"客户端推算 vs 服务器结果"不一致的隐患。

二、安装与启动

安装

  1. 解压 SwimmingTimingSystem-Setup-v2026.06.xx.zip
  2. 双击 Setup.exe → 按提示一键安装到默认目录
  3. 桌面/开始菜单出现快捷方式

启动顺序

  1. 主控 PC 先开 SwimmingScoreboard.exe
  2. 大屏机 PC 开浏览器 → 双击 display.html → 输入主控 IP → 全屏
  3. 其它端按需启动（计时席 / 裁判席）

加载赛事

主控启动会自动加载上次打开的赛事（last_competition.txt 记忆）。手动加载：赛事管理与报名 → 加载赛事 按钮 → 选 JSON 文件。

三、比赛规则 新

在 赛事管理与报名 → 比赛参数设置管理 顶部黄底卡片选择：

规则说明
国际比赛 (FINA)男/女 分项, 同年龄组同组, 单组排名按时间, 总排名按 性别×组别
国内大赛 (中国游协)同 FINA, 国内执行差异由本地规程补充
U系列青少年游泳比赛 (默认)允许 男女并项 / 跨年龄并项 / TRI 参赛 / 直接决赛多组 / 组内单一名次 / 总排名按 性别×组别 拆

规则保存到比赛档案 (CompetitionRule 字段)。U 系列规则下，系统允许：

  • 男女同组比赛: schedule.Gender = "男女", swimmer.Gender 仍是真实的男/女
  • 不同组别同组: schedule.AgeGroup = "12~15岁组" 区间, swimmer 实际是 12-13/14-15
  • TRI 运动员参赛: 试游, 不入排名, 时间正常显示
  • 直接决赛多组: 不必跑预赛, 直接按报名时间排多组决赛
  • 组内单一名次: 同组按时间 1-N 排, 不分男女拆
  • 总排名按性别×组别拆: 项目完赛后, 各性别×组别 各出一张子排名

四、赛事管理与报名

赛事信息

顶部填赛事名称、日期、地点、组织方、裁判等。保存赛事信息 按钮持久化到 JSON 档案。

运动员管理

  • 添加运动员 — 单个录入
  • 修改选中 — 临场修改 (名字拼错、改代表队等)
  • 删除选中 — 撤报名
  • 导入 CSV / 导出 CSV / 导出模板 — 批量
  • 号码区间设置 — 自动分配比赛号

接力队管理

支持 4 棒接力 (4×50 / 4×100)。棒次上移/下移/更换队员 临场调整。

赛程

  • 秩序册生成向导 — 自动按 项目 × 组别 × 性别 排日程
  • 项目自动分组 — 按报名成绩 seed 入组
  • 手动分组 — 操作员逐道指定
  • 追加分组 — 临场加道
  • 打印日程表 / 导入/导出/下载 (Excel)

出场编排

左侧选项目→性别→组别→赛次, 右侧表格显示该组所有道位。底部 8 个按钮：

  • 上移 / 下移 — 调整道次顺序
  • 交换泳道 — 选中 + 弹窗选目标
  • 增加到本组 — 加入空道
  • 移出本组 — 临时退赛
  • 临时加人 — 弹窗录入新选手并放入本组
  • 保存修改

核心动作按钮 (中部)

按钮颜色动作

泳道操作 (按选道)

输入道次 (左上 LaneInput), 然后点：

  • DNS — 弃权
  • DNF — 未完成
  • DSQ — 犯规取消 新规则:
    • 个人项目: 清 最终成绩 + 所有分段 + 反应时
    • 接力项目: 弹窗问"犯规棒次 N" → 保留 1~N-1 棒分段, 清 第N棒起的分段 + 最终成绩
  • TRI — 试游 (备注栏显 TRI, 成绩正常显, 不入排名)
  • 取消备注 — 撤销 DSQ/DNS/DNF/TRI 标记, 恢复参赛状态
  • 盲表成绩 — 用盲表时间补当前分段
  • 手动输入 — 弹窗输入成绩 (硬件失灵兜底)

成绩存盘路径 新

点击顶部 📁 成绩存盘路径 按钮:

  • 输入目录 (默认 安装目录/Documents/成绩txt)
  • "浏览..." 选目录
  • "保存" 持久化 / "清空" 关闭自动保存 / "取消"

每次"确认本组成绩"后自动写入两个文件到此目录：

  1. 成绩 txt: {场号}-{项号}-{组号}.txt (变列格式: 道次 + 最终 + 分段×n + 反应时×m)
  2. 比赛日志 PDF: {比赛项目+赛次+组号}+比赛日志.pdf (含项目/日期/时间/地点/per-lane 完整事件流, Edge headless 转 PDF; 失败保留 HTML)

七、男女并项 新

核心规则

  • schedule.Gender = "男女" — 项目允许男女同组比赛
  • swimmer.Gender = "男" / "女" — 个人仍是真实性别
  • 组内排名: 单一 1-N 按时间, 不分男女拆 (大屏不出现两个第1名)
  • 总排名: 按 性别×组别 拆子表, 每个性别各自第1名
  • 跨年龄并项: schedule.AgeGroup = "12~15岁组" 区间, swimmer.AgeCategory 是真实子组 (12-13 / 14-15)

数据流支持

函数男女并项支持
GetCurrentHeatSwimmers_currentGender == "男女" 时 男+女+男女 都过
MatchesAgeGroup支持区间 "12~15岁组" ⊇ "12-13岁组" + "14-15岁组" (含半角/全角 ~)
BuildEventNumberMap按 (Gender, EventName, AgeGroup) 3 维 keying, 同性别同项目 但不同年龄组 有独立项次
GetEventRankingsSplit总排名按 (实际性别, 实际年龄组) 拆
CheckRecords用 swimmer.Gender (单一) 对比 record.Gender, 不再因 _currentGender = "男女" 漏检破纪录

八、TRI / DSQ / DNS / DNF

TRI (试游)

  • 道次按 TRI 按钮 → 备注栏显 "TRI"
  • finalTime 正常显示 (与 DSQ/DNS/DNF 不同)
  • 不参与排名 (与 DSQ/DNS/DNF 同款排除)
  • 不影响其他人的名次
  • "计时复位" 不清 TRI (用户要求: 只 "取消备注" 能清)

DSQ (取消资格)

  • 个人项目: 清 最终成绩 + 所有分段 + 反应时
  • 接力项目: 弹窗问"犯规棒次 N", 保留 1~N-1 棒分段, 清 第N棒起的分段 + 最终成绩 新
  • 备注栏显 "DSQ" (红色)
  • 不入排名

DNS (弃权) / DNF (未完成)

  • 备注栏显 "DNS" / "DNF" (红色)
  • 不入排名

抢跳判罚

硬件检测到抢跳 → 反应时单元格标红 (state.IsSuspectFalseStart). 裁判可手动 DSQ. 不自动 DSQ.

十一、远程控制

race_control.html

计时控制网页端. 浏览器打开, 输入主控 IP 连接. 功能: 道次操作 / 开始比赛 / 停表 / 确认成绩 / 设备状态管理 / 盲表成绩 / 手动输入 / 打印成绩 / 等同步.

control.html

大屏控制网页端. 主要功能:

  • 大屏视图切换 (12 个按钮)
  • 成绩发布到大屏 (选已完赛项目)
  • 记录显示/隐藏 4 端切换
  • 备注栏 显反应时/不显 4 端切换
  • PPT 播放 (主控 PC 选文件)
  • 大屏样式 远程控制
  • 📄 成绩 txt 输出 新 (选已完赛组下载到本机)
