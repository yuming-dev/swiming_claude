┌──────────────────────────────────────────────────────────────┐
│ 一、概述                                                     │
└──────────────────────────────────────────────────────────────┘

本手册指导操作员把已在开发机预先导入好的比赛档案，部署到现场
赛事服务器（主控 PC）+ 多块大屏 + 副控 + 报名台，并完整跑通
一场比赛。

本系统由以下组件构成（已全部装在安装包里）：
  - SwimmingScoreboard.exe      主控（计时主服务器 / 数据中枢）
  - RemoteTimingControl.exe     远程计时控制 (副控)
  - RemoteDisplayControl.exe    远程显示控制
  - RegistrationTool.exe        报名台
  - ScheduleEditor.exe          赛程编排端
  - Web/display.html            大屏 (LED / 投影)
  - Web/control.html            显示模式控制（网页）
  - Web/leaderboard.html        排名屏
  - Web/race_control.html       计时控制（网页）
  - Web/register.html           检录 / 报名（网页）

所有副控 / 大屏 / 浏览器端通过 WebSocket（端口 3002）连到主控 PC。


┌──────────────────────────────────────────────────────────────┐
│ 二、机器角色（单机模式 vs 多机模式）                         │
└──────────────────────────────────────────────────────────────┘

【单机模式】最简单：一台 PC 跑所有
  - 主控 SwimmingScoreboard.exe
  - 同机浏览器打开 display.html 投到 LED
  - 同机浏览器打开 leaderboard.html 投到看台屏

【多机模式（推荐）】生产部署
  ┌─────────────────────────────────────────────────────┐
  │  PC 1 (主控)          IP 固定 192.168.1.100         │
  │  ├─ SwimmingScoreboard.exe                          │
  │  ├─ 接硬件计时器 (USB串口/网线)                     │
  │  └─ 输出大屏 / 副控的数据中枢                       │
  │                                                       │
  │  PC 2 (大屏主机)      IP 192.168.1.101              │
  │  └─ 浏览器全屏 display.html?host=192.168.1.100      │
  │                                                       │
  │  PC 3 (排名屏主机)    IP 192.168.1.102              │
  │  └─ 浏览器全屏 leaderboard.html?host=192.168.1.100  │
  │                                                       │
  │  PC 4 (计时台 / 副控) IP 192.168.1.103              │
  │  └─ RemoteTimingControl.exe / race_control.html     │
  │                                                       │
  │  PC 5 (检录 / 报名)   IP 192.168.1.104              │
  │  └─ RegistrationTool.exe / register.html            │
  └─────────────────────────────────────────────────────┘

所有机器接同一台路由器/交换机, 主控 PC IP 必须固定。


┌──────────────────────────────────────────────────────────────┐
│ 三、安装步骤                                                 │
└──────────────────────────────────────────────────────────────┘

每台需要装系统的 PC 都按以下步骤：

1. 把 SwimmingTimingSystem-Setup-v2026.06.01.zip 拷到目标机器
   （U 盘 / 微信 / QQ 文件传输 / 共享文件夹）

2. 解压 zip → 双击 Setup.exe

3. 选安装目录（默认 C:\Program Files\SwimmingScoreboard\，
   建议留默认；磁盘空间不足时改到 D 盘）

4. 安装完成后桌面会有 5 个快捷方式：
     SwimmingScoreboard（主控）
     RemoteTimingControl（远程计时）
     RemoteDisplayControl（远程显示控制）
     RegistrationTool（报名）
     ScheduleEditor（编排）

5. （可选）创建桌面快捷方式直接打开 display.html / leaderboard
   .html，方便大屏/排名屏开机自启：
     右键桌面 → 新建 → 快捷方式
     位置：start chrome --kiosk "file:///安装路径/SwimmingScoreboard/Web/display.html"


┌──────────────────────────────────────────────────────────────┐
│ 四、比赛档案部署                                             │
└──────────────────────────────────────────────────────────────┘

只在主控 PC 上做这步（副控不需要，会从主控 WebSocket 拉数据）。

1. 准备 2 个文件（从开发机 / U 盘拷过来）：
   - 2026甘肃省浩沙杯U系列青少年游泳俱乐部联赛（定西站）.json
   - last_competition.txt

2. 找到主控 PC 安装目录的 Database 子目录，例如：
   C:\Program Files\SwimmingScoreboard\Database\

3. 把上面 2 个文件放到对应位置：
   - .json 放到 Database\ 里
   - last_competition.txt 放到 Database\ 的上一级（与
     SwimmingScoreboard.exe 同目录）

4. 启动 SwimmingScoreboard.exe → 应自动加载比赛档案，主窗口
   "赛事管理" Tab 能看到比赛名称 + 27 个单位 + 1120 运动员。

5. 验证 4 件事：
   ✓ 赛事管理 Tab 比赛名称、起止、场地、主办/承办 都正确
   ✓ 报名管理 1120 条注册全部到位
   ✓ 赛程 82 项 (28+26+28) 排序正常，开赛时间符合 PDF
   ✓ 比赛控制 → 赛程导航树展开能看到 7 个组别 × 13 项目


┌──────────────────────────────────────────────────────────────┐
│ 五、硬件计时器连接                                           │
└──────────────────────────────────────────────────────────────┘

只在主控 PC 上做这步。

1. 物理连接：把硬件计时器和主控 PC 接好
   - USB 串口型号：插 USB 线
   - 网线型号：交叉网线或经过交换机
   - 注意计时器电源 + 触板 / 出发台 / 盲表 线缆是否全到位

2. SwimmingScoreboard 主控 PC → 比赛控制 → 系统硬件 区
     ┌────────────────────────┐
     │ 连接硬件 / 设备测试      │
     │ 串口/IP/端口 参数设置    │
     └────────────────────────┘

3. 设置串口/网络参数后点"连接硬件"
   - 状态指示灯变绿 = 已连接
   - 右上角"硬件计时器"行显示"连接"

4. 点"设备测试"，跑一遍：
   - 每道触板 → 单击触板，对应道格颜色应变
   - 出发台 → 跳板按一下，蜂鸣指示
   - 盲表（如配） → 按一下盲表按键
   - 计时清零、起跑信号都测一遍

5. 在"比赛参数设置管理" Tab 配好：
   - 泳道数（看场地, 通常 10 / 8 / 6）
   - 池长（50 / 25 米）
   - 触板安装：单端 / 双端
   - 出发台位置：左 / 右
   - 关闭时间 / 反应时窗口 / 分段显示时间 等


┌──────────────────────────────────────────────────────────────┐
│ 六、网络配置 + 副控/大屏连接                                 │
└──────────────────────────────────────────────────────────────┘

【主控 PC】
1. 控制面板 → 网络 → 给主控 PC 设固定 IP
   例：192.168.1.100 / 掩码 255.255.255.0 / 网关 192.168.1.1
2. 防火墙允许 SwimmingScoreboard.exe 入站 (TCP 3002)
   首次运行 Windows 会弹"允许网络访问"，选"专用网络"
3. 电源管理 → "永不进入睡眠" + "永不关闭显示器"
4. 关闭 Windows 自动更新（避免比赛中重启）

【副控 / 大屏 / 排名屏端】
- 启动 EXE 或浏览器打开 .html
- 弹出"连接主服务器"对话框 → 输入 192.168.1.100 → 连接
- 成功后状态指示"已连接"（绿色）

【大屏全屏】
- 浏览器打开 display.html → 点击页面任意位置触发全屏
- 或在快捷方式参数加 --kiosk 让 Chrome 启动即全屏

【大屏样式远程统一调整 (v2026.06.01 新功能)】
- 任一控制端 (主控 / control.html / RemoteDisplayControl) 都可以
  通过"🎨 大屏样式"按钮远程调整：
  · 底色 (8 预设 + 自定义 hex)
  · 字号 (0.8x ~ 3.0x, LED 屏推荐 1.8x ~ 2.5x)
  · 9 处文字颜色 + 字体
- 改动实时推送到所有大屏，服务器持久化保存
  (改完不必每台屏单独再设)

   - 颁奖证书

   并恢复数据


┌──────────────────────────────────────────────────────────────┐
│ 八、赛中操作流程                                             │
└──────────────────────────────────────────────────────────────┘

每一组的标准流程：

  1. 主控 → 比赛控制 → 从"赛程导航"选当前项目
       (例: 第1场 项次1 女 200米自由泳 决赛 第1组)
  2. 检查各道运动员是否齐 (检录后某些道可能 DNS)
       DNS 的道 → 点该道"标记 DNS"按钮
  3. 点 "准备就绪" → 各道出发台变绿，硬件等待
  4. 点 "发令"（或硬件按发令按钮 → 自动同步）
  5. 比赛进行中：
     - 大屏滚动时间走动
     - 每道触板自动捕获分段
     - 名次实时更新 (1-2-2-4 标准并列)
  6. 比赛结束（所有运动员完赛）：
     - 名次锁定，第 1 名成绩高亮停留 N 秒
     - 大屏自动切到本组成绩榜
  7. 裁判判罚（如有 DSQ / DNS / DNF）
     → 主控 → 该道"判罚"按钮 → 选 DSQ
     → 大屏备注栏立即变红显示 DSQ
     → 破纪录标识自动转给新晋第 1 名（如有）
  8. 点 "确认本组成绩" → 成绩锁定入档
  9. 点 "计时复位" → 进下一组

每场比赛结束（约 26-28 个项目跑完）：
  - 主控 → "成绩与排名" Tab → 检查各项目排名
  - 按需打印各项目成绩单
  - 备份当日比赛档案到 U 盘（每天结束都备份！）


┌──────────────────────────────────────────────────────────────┐
│ 九、应急方案                                                 │
└──────────────────────────────────────────────────────────────┘

【硬件计时器断连】
  现象：大屏滚动时间停留 / 各道触板无反应
  处理：
    1. 主控 → 比赛控制 → 查"硬件计时器"连接状态
    2. 状态变灰 → 点"重新连接"
    3. 仍失败 → 检查 USB / 网线物理连接
    4. 实在不行 → 立即切到手动计时 (盲表 + 手工输入)
       该组成绩用裁判的盲表/秒表，主控"手工输入成绩"

【主控 PC 蓝屏 / 重启】
  比赛档案在 Database\ 已落盘，绝大多数情况数据不丢。
  处理：
    1. PC 重启完成 → 启动 SwimmingScoreboard.exe
    2. 应自动加载 last_competition.txt 指定的比赛档案
    3. 重连硬件计时器
    4. 副控 / 大屏会自动重连主服务器
    5. 当前正在进行的那一组可能丢失：从赛程选到该组重打
  防御：每天比赛结束都备份比赛档案到 U 盘！

【大屏死机 / 浏览器卡顿】
  处理：
    1. 关闭浏览器 → 重开 → 输入服务器 IP 重连
    2. 大屏样式（底色 / 字号 / 9 处文字）会从服务器自动同步
       回来（无需重新设置）

【副控 / 计时台死机】
  处理：跟大屏一样，关掉重启即可，会自动重连

【主服务器 IP 变了 / 网络故障】
  处理：
    1. 主控 PC 重新设固定 IP，例 192.168.1.100
    2. 副控 / 大屏 重新打开连接对话框输入新 IP

【纸质成绩 / 印章遗失】
  本系统支持"打印成绩单"功能，提前打一份备用
