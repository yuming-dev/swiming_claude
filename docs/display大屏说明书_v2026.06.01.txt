┌──────────────────────────────────────────────────────────────┐
│ 一、概述                                                     │
└──────────────────────────────────────────────────────────────┘

display.html 是游泳赛事管理系统的"观众/裁判席大屏"前端，连上主服
务器 SwimmingScoreboard.exe 后自动接收比赛实时数据并渲染；前端
不做任何重算、不缓存比赛数据，纯渲染层。

数据来源原则
    所有名次、反应时、分段、运动员信息、破纪录标识、滚动时间均
    由主服务器统一计算后广播。display.html 只渲染，不重算、不
    本地推算。滚动时间直接显示硬件 0x7F 派生的服务器值，禁本地
    时钟插值。

技术栈
    纯 HTML + CSS + JavaScript（无依赖），WebSocket 收数据。
    可在任何现代浏览器(Edge / Chrome / Firefox) 直接打开。

部署形态
    通常 LED 显示墙连一台机器，浏览器全屏运行 display.html。
    多块屏并存也支持，所有 display.html 共享服务器推送的样式。


┌──────────────────────────────────────────────────────────────┐
│ 二、启动与连接服务器                                         │
└──────────────────────────────────────────────────────────────┘

【启动方式】
    方式 1：双击 display.html 文件
    方式 2：浏览器地址栏输入
            file:///安装路径/SwimmingScoreboard/Web/display.html
    方式 3：URL 加参数直连
            display.html?host=192.168.1.100

【首次打开】
    显示"连接主服务器"遮罩 → 输入主服务器 IP → 点"连接"。
    成功后遮罩消失，进入欢迎页 / 比赛画面。
    服务器 IP 记到 localStorage，下次自动复用。

【全屏】
    点击页面任意位置触发全屏（F11 也可）。

    提示：LED 大屏务必全屏，否则浏览器标题栏挤占空间，vh 字号
          算出来偏小。

【关闭】
    刷新或关闭页面会有"确定要关闭大屏幕显示？"提示，防误关。

【自动重连】
    WebSocket 断开 → 自动重连 + 显示遮罩。重连成功后画面立即
    恢复，所有数据由服务器重发 snapshot，不会丢任何状态。


┌──────────────────────────────────────────────────────────────┐
│ 三、主要显示视图（9 种）                                     │
└──────────────────────────────────────────────────────────────┘

顶部标题栏始终显示比赛名称（左/中）+ WR/CR 纪录（右上角）。
下方主区域按主控发来的"视图指令"切换：

    1) 欢迎页 (welcome)
       居中显示比赛名称 / 副标题 / Logo, 比赛未开始时常驻。

    2) 比赛中 (race)                ← 最常用，详见 §四
       实时显示当前组各道运动员、分段成绩、名次、滚动时间。

    3) 出发表 (start list)
       当前组报名信息表。列：道次 / 姓名 / 代表队。
       v2026.06.01 移除"号码"列。

    4) 总排名 (event ranking)
       本项目全部小组完赛后, 按成绩排序的最终名次。
       列：名次 / 姓名 / 代表队 / 成绩 / 备注。
       v2026.06.01 移除"号码"列, 新增"备注"列：
           - 晋级 Q (绿)
           - 破/平纪录 WR / CR / NR / AR / 等 (金)
           - DSQ / DNS / DNF 等 (红, 独占)
           - 多项同存用 " \ " 分隔, 例: Q \ WR \ CR
       超过 10 行自动翻页（间隔 = 参数"大屏翻屏时间"，默认 5s）。

    5) 公布成绩 (published result)
       某一组成绩"公布"后的展示画面。

    6) 团体积分 (team standings)
       各代表队累计积分排名（金/银/铜数 + 总分）。

    7) 纪录榜 (records)
       项目 / 类型 / 保持者 / 代表队 / 成绩 / 日期 全列表。

    8) 颁奖典礼 (awards)
       三人领奖台：金牌居中、银牌左、铜牌右，依次淡入。

    9) 媒体播放 (media)
       由主控推送的图片 / 视频，占满全屏播放。

【实时名次】
    服务器统一计算并广播 (ComputeLiveRanks)：已完赛 → 未完赛；
    同分段同累计时间 → 并列名次 1-2-2-4 标准；前端只渲染。

【DSQ 后 WR/CR 自动转移】（v2026.06.01）

    自动行为：服务器重新比对纪录库，将 WR 标识从 #1 转到 #2；
              再 DSQ #2 → WR 再转到 #3；直到出现合法第 1 名。
    "确认本组成绩"后服务器才把仍有 RecordNote 且非 DSQ 的成绩
    入库到纪录管理 (纪录库)。

┌──────────────────────────────────────────────────────────────┐
│ 七、远程样式控制（v2026.06.01 新增，重要）                  │
└──────────────────────────────────────────────────────────────┘

【背景与设计】
    底色、字号、9 处文字配置由 **主服务器集中托管**：
    - 持久化到 SwimmingScoreboard\display_style.json
    - 多个 display.html 共享一套样式（服务器是唯一权威源）
    - 任意控制端改动 → 服务器广播 → 所有 display.html / 控制端
      实时同步
    - 服务器重启后样式自动恢复

【可控端（4 个）】

    1) display.html 自己（右下角 ⚙/字/文 三按钮）
       本地修改自动推送到服务器, 服务器再广播给其它客户端

    2) control.html （显示模式控制网页）
       面板底部新按钮 "🎨 大屏样式 (底色 / 字号 / 文字)"
       点击弹出对话框, 含 3 区控件（底色 / 字号 / 9 处文字）

    3) RemoteDisplayControl.exe (远程显示控制 WPF EXE)
       底部新按钮 "🎨 大屏样式"
       弹出独立窗口, 含相同 3 区控件

    4) 主控 PC (SwimmingScoreboard.exe)
       "比赛控制 → 显示控制" 区块下方紫色按钮
       "🎨 大屏样式 (底色/字号/文字)"
       弹出对话框

【WebSocket 协议】

    控制端 → 服务器：
        SET_DISPLAY_STYLE
            data: { bg?, fs?, textStyle?, textStyleMerge? }
        GET_DISPLAY_STYLE
            (用于打开面板时拉取当前值)

    服务器 → 所有客户端：
        DISPLAY_STYLE_PUSH
            data: { bg, fs, textStyle }

    textStyleMerge=true 表示局部合并（只更新指定字段）；
    textStyleMerge=false / 未设 表示完整替换。

【典型用法】

    场景 A：现场操作员想把比赛大屏字号调大一点
        在 control.html 网页 → 点 "🎨 大屏样式" → 字号 [+]
        → 大屏立即跟着放大

    场景 B：裁判长想统一改比赛名称颜色为金色
        主控 PC → 比赛控制 Tab → 显示控制 → "🎨 大屏样式"
        → 文字样式区 → 比赛名称 → 改色为 #f59e0b → ↻
        → 所有大屏同时变成金色比赛名称

    场景 C：远程操作员想统一改大屏背景为极光蓝
        RemoteDisplayControl.exe → "🎨 大屏样式" → 底色 →
        填 linear-gradient(...) → 回车
        → 所有大屏底色统一切换

【本地 vs 远程】
    display.html 自己的 ⚙/字/文 面板修改 = 也走服务器同步路径
    （v2026.06.01 起统一）
    断网时本地 localStorage 还在做兜底保存，重新连接到服务器后
    服务器推送的最新样式会覆盖本地。

Q1: LED 屏上字太小看不清
A:  点右下角 "字" 按钮 → 按 [+] 调到 2.0x ~ 3.0x。
    或按 Ctrl + 多按几次。每加 0.1 即时生效。
    更佳：用 control.html / 主控 PC / RemoteDisplayControl
          远程统一调整（一改全屏同步）。

Q2: 字号调过头, 一行装不下
A:  Ctrl 0 一键回到 1.0x, 重新调到合适倍数。

Q3: 比赛项目/滚动时间/名次的颜色不显眼
A:  右下角 "文" 按钮 → 文字样式面板 → 找到对应行 → 改色。

Q4: 多个大屏样式不一致
A:  v2026.06.01 起样式由服务器集中托管, 应自动同步。
    若不一致检查各显示终端是否都连上同一台服务器（IP 正确）。

Q5: 我在 RemoteDisplayControl 改了字号, 大屏没反应
A:  确认 RemoteDisplayControl 已连接服务器（顶部地址绿色"已连接"）。
    确认大屏 display.html 同样连接到了主服务器。
    服务器收到 SET_DISPLAY_STYLE 后会立即广播 DISPLAY_STYLE_PUSH。

Q6: 比赛中的滚动时间在确认成绩 + 计时复位后还显示上组时间
A:  v2026.06.01 已修复。非比赛主视图(本组成绩/总排名/颁奖等)
    下不再被硬件残留 0x7F 帧覆盖。

Q7: 自动晋级窗口确认后大屏闪烁
A:  v2026.06.01 已修复。display.html 忽略所有非 SHOW_* 的控制
    通知消息（STAGE_COMPLETE / PROMOTION_DONE 等不再误改视图）。

Q8: 接力 "混合子" 错显
A:  v2026.06.01 已修复。混合性别显示为"混合", 不再加"子"。

Q9: 接力比赛只想看当前棒, 不想看全部 4 棒
A:  当前版本只支持全部 4 棒同列显示, 当前棒已经高亮金色用于
    强调。如需"只显当前棒"模式, 联系开发者加开关。

Q10: 想用自己的图片做大屏底色
A:  右下角 ⚙ → 自定义 → 图片 → 选择本地图片 → 自动转 base64
    存入 localStorage（注意图片不要超过几 MB）。
    若想统一推到所有大屏：复制图片转换的 base64 字符串到 control
    .html 大屏样式对话框的底色输入框（或直接写 url(data:...) ）。

Q11: 全屏退出后还能再进去吗?
A:  按 ESC 后, 再次点击页面任意位置即可重新进入全屏。

Q12: 浏览器 Ctrl+/- 失效
A:  display.html 已主动拦截这两个组合键用于字号缩放。这是设计
    行为, 避免与浏览器原生缩放冲突。

    删除对应键。全部清空可一键回到出厂默认。
