一、概述

display.html 是游泳赛事管理系统的"观众/裁判席大屏"前端：连上主服务器(比赛控制端 SwimmingScoreboard.exe) 后，自动接收比赛实时数据并渲染，无需任何本地配置，不储存比赛数据。

数据来源原则：所有名次、反应时、分段、运动员信息都由主服务器统一计算后广播过来，display.html 只负责渲染，不做任何本地推算或插值。滚动时间也来自硬件 0x7F 派生的服务器值，禁本地时钟插值。

技术栈：纯 HTML + CSS + JavaScript（无依赖），WebSocket 接收数据。可在任何现代浏览器(Edge / Chrome / Firefox) 直接打开。

二、启动与连接服务器

启动方式

  • 方式 1：双击 display.html 文件
  • 方式 2：浏览器地址栏输入 file:///安装路径/SwimmingScoreboard/Web/display.html
  • 方式 3：URL 加参数直连 — display.html?host=192.168.1.100

首次打开

显示"连接主服务器"遮罩 → 输入主服务器 IP → 点"连接"。成功后遮罩消失，进入欢迎页 / 比赛画面。服务器 IP 被记到 localStorage，下次自动复用。

全屏

点击页面任意位置触发全屏 (F11 也可)。

提示：LED 大屏部署时务必全屏，否则浏览器标题栏/任务栏会挤占空间，导致 vh 字号算出来偏小。

关闭

刷新或关闭页面会有"确定要关闭大屏幕显示？"提示，防误关。

三、主要显示视图

顶部标题栏始终显示比赛名称 + WR / CR 纪录（右上角）。下方主区域按主控发来的"视图指令"切换 9 种状态：

编号视图说明
1欢迎页 (welcome)居中显示比赛名称 / 副标题 / Logo, 比赛未开始时常驻。
2比赛中 (race)实时显示当前组各道运动员、分段成绩、名次、滚动时间。最常用，详见 §四。
3出发表 (start list)当前组所有运动员的报名信息表（道次 / 号码 / 姓名 / 代表队）。
4总排名 (event ranking)本项目全部小组完赛后, 按成绩排序的最终名次。超过 10 行自动翻页（间隔参数从主控"大屏翻屏时间"读）。
5公布成绩 (published)某一组成绩"公布"后的展示画面（与比赛中视图同布局，但行已按名次排序固定不动 + 显示破纪录标记）。
6团体积分 (team)各代表队累计积分排名（金 / 银 / 铜数 + 总分）。
7纪录榜 (records)项目 / 类型 / 保持者 / 代表队 / 成绩 / 日期 全列表。
8颁奖典礼 (awards)三人领奖台：金牌居中、银牌左、铜牌右，依次淡入显示。
9媒体播放 (media)由主控推送的图片 / 视频, 占满全屏播放。

行内容刷新规则

列刷新逻辑
成绩完赛后显示终点成绩；比赛中显示最新分段成绩 (5 秒后自动消失, 时长参数为主控"分段成绩显示时间", 默认 5 秒)。

2) 破/平纪录 CR / NR / AR / WR (金)
3) 反应时（最近一次抢跳秒数, 抢跳可疑标红）

五、右下角设置按钮 (3 个)

右下角从下到上 3 个圆形按钮，平时半透明 (45%), 鼠标悬停变亮 (100%)：

  • ⚙   大屏底色 (打开"底色"面板)
  • 字   大屏字号 (打开"字号"面板)
  • 文   文字样式 颜色/字体 (打开"文字"面板)

⚙   大屏底色 (Background)

提供 5 类预设 + 1 类自定义：

  • 纯色：8 个色板 (深蓝/黑/灰/卡其/酒红/松绿/海蓝 等)
  • 渐变：8 个层次感渐变
  • 高级混合：8 个深度感网格状底色
  • 灰度：6 档不同灰度
  • 图案：6 种横纹 / 格纹 / 光晕等
  • 自定义：颜色拾色器 + 16 进制输入 + 上传本地图片做底

底部"恢复默认 (深邃蓝)"还原为 #0f172a。数据持久化：localStorage('swimDisplayBg')。

字   大屏字号 (Font Scale)

LED 屏宽高比往往很扁，CSS 默认用 vh 算出来的字号偏小看不清。此面板允许全局缩放所有"比赛内容"区字号 (0.8x ~ 3.0x, 步进 0.1)。

控件 / 快捷键动作
[−] 1.5x [+]点击调整, 数值实时显示
恢复 1.0x一键重置
Ctrl +字号 +0.1
Ctrl −字号 −0.1
Ctrl 0重置为 1.0x
已 preventDefault 覆盖浏览器原生缩放, 避免冲突。

作用范围 (会被缩放)：顶部标题 / 比赛项目 / 滚动时间 / 道次 / 名次 / 姓名 / 代表队 / 成绩 / 备注 / 总排名 / 出发表 / 团体 / 纪录 / 颁奖。

不缩放 (保持固定可点)：右下角设置按钮、3 个设置面板内部、连接服务器遮罩。

数据持久化：localStorage('swimDisplayFs')。

文   文字样式 (Text Style：颜色 + 字体)

9 处文字可以独立配置颜色和字体。面板呈表格状，每行：[标签] [取色器] [16 进制] [字体下拉] [↺]

标签默认色默认字体
比赛名称白微软雅黑
比赛项目白微软雅黑
滚动时间金Consolas (等宽)
道次灰微软雅黑
名次白微软雅黑
姓名白微软雅黑
代表队灰微软雅黑
成绩白Consolas (等宽)
备注红微软雅黑

可选字体 (10 种)：微软雅黑 / 黑体 / 宋体 / 楷体 / 仿宋 / 隶书 / 幼圆 / Arial / Consolas (等宽) / Impact。

按钮：

  • ↺ 单行恢复默认 (该元素颜色 + 字体)
  • 全部恢复默认 一键全部 9 处复位 (有确认弹窗)
颜色优先级 (高 → 低)：
1. 判罚色 (DSQ 红 / 破纪录 金) — JS 内联色, 强制不可被覆盖。
2. 奖牌色 (1 金 / 2 银 / 3 铜) — 名次为 1/2/3 时强制显示, 不受用户"名次"颜色影响, 4+ 名次才用用户色。
3. 用户在文字样式面板里的自定义色 — 其他场景生效。

数据持久化：localStorage('swimDisplayTextStyle'), 存储格式 {key:{c:'#..', f:'..'}, ...} JSON。旧版 swimDisplayTitleColor (只配比赛名称色) 启动时自动迁移到本表 title.c 字段后被删除。

六、断线重连

WebSocket 断开后 display.html 会自动尝试重连。连续重连失败会弹出"连接主服务器"遮罩, 用户可重新输入 IP。重连成功后画面立即恢复, 不会丢任何数据 (服务器会重发 snapshot)。

七、常见问题排查

问题解决方案
LED 屏上字太小看不清点右下角 字 按钮 → 按 [+] 调到 2.0x ~ 3.0x。或者按 Ctrl + 多按几次。每加 0.1 即时生效。
字号调过头, 一行装不下Ctrl 0 一键回到 1.0x, 重新调到合适倍数。
比赛项目/滚动时间/名次的颜色不显眼右下角 文 按钮 → 文字样式面板 → 找到对应行 → 改色。比如把"比赛项目"改成金色 (#f59e0b), 跟时间一样醒目。
接力比赛只想看当前棒, 不想看全部 4 棒当前版本只支持全部 4 棒同列显示, 当前棒已经高亮金色用于强调。如需"只显当前棒"模式, 请联系开发者加开关。
字号或颜色改完后, 换一台机器没生效这些参数存在浏览器本地 localStorage, 每台显示终端独立保存。需要在每台 LED 显示机上重新配置一次, 或将整个用户数据目录复制过去 (路径因浏览器而异)。
浏览器 Ctrl+/- 失效display.html 已主动拦截这两个组合键用于字号缩放。这是设计行为, 避免与浏览器原生缩放冲突。如需浏览器原生缩放, 请关闭 display.html 切到其他标签页。
全屏退出后还能再进去吗?按 ESC 后, 再次点击页面任意位置即可重新进入全屏。
想用自己的图片做大屏底色右下角 ⚙ → 自定义 → 图片 → 选择本地图片 → 自动转 base64 存入 localStorage。注意图片不要超过几 MB, 否则刷新加载会慢。

八、localStorage 键一览

键名含义
swimServerHost主服务器 IP (字符串)
swimDisplayBg大屏底色 (CSS background 值)
swimDisplayFs字号倍数 (0.8 ~ 3.0)
swimDisplayTextStyle9 处文字颜色 + 字体 JSON
swimDisplayTitleColor⚠ 旧版残留 (启动自动迁移后删除)

清理：浏览器开发者工具 → Application → Local Storage → 删除对应键。全部清空可一键回到出厂默认。
