一、概述

display.html 是游泳赛事管理系统的"观众/裁判席大屏"前端，连上主服务器 SwimmingScoreboard.exe 后自动接收比赛实时数据并渲染。前端不做任何重算、不缓存比赛数据，纯渲染层。

数据来源原则：所有名次、反应时、分段、运动员信息、破纪录标识、滚动时间均由主服务器统一计算后广播。display.html 只渲染，不重算，不本地推算。滚动时间直接显示硬件 0x7F 派生的服务器值。

技术栈：纯 HTML + CSS + JavaScript（无依赖），WebSocket 收数据。可在任何现代浏览器(Edge / Chrome / Firefox) 直接打开。

部署形态：通常 LED 显示墙连一台机器，浏览器全屏运行 display.html。多块屏并存也支持 — v2026.06.01 起样式由服务器集中托管，所有大屏共享一套样式。

二、启动与连接服务器

启动方式

  • 双击 display.html 文件
  • 浏览器地址栏输入 file:///安装路径/SwimmingScoreboard/Web/display.html
  • URL 加参数直连 — display.html?host=192.168.1.100

首次打开

显示"连接主服务器"遮罩 → 输入主服务器 IP → 点"连接"。成功后遮罩消失，进入欢迎页 / 比赛画面。服务器 IP 记到 localStorage，下次自动复用。

全屏

点击页面任意位置触发全屏 (F11 也可)。

提示：LED 大屏务必全屏，否则浏览器标题栏挤占空间，vh 字号算出来偏小。

自动重连

WebSocket 断开 → 自动重连 + 显示遮罩。重连成功后画面立即恢复，所有数据由服务器重发 snapshot（含当前样式），不会丢任何状态。

五、本组成绩视图（v2026.06.01 新规则）

确认本组成绩后大屏切换到本组成绩榜，使用新的固定行高 + 翻页规则：
  • 每行固定 7.5vh，不再随道数自动拉伸
  • 每屏最多显示 10 行
  • 超过 10 人 → 自动翻页，间隔 = "大屏翻屏时间"（默认 5s）
  • 右下角显示 1 / 2 翻页指示
  • 少人比赛（如 6 道）行高不再被拉伸到视觉失真

右上角滚动时间 v2026.06.01 修复

本组成绩 / 总排名 / 公布成绩 / 颁奖等视图不显示走时；确认成绩后计时复位不再让右上角错显上组比赛时间（硬件 0x7F 残留值在非比赛主视图下被忽略）。

六、本地设置按钮（display.html 自身右下角）

从下到上 3 个圆形按钮（平时半透明 45%，鼠标悬停 100%）：

  • ⚙   大屏底色
  • 字   大屏字号
  • 文   文字样式（颜色 + 字体）

本地面板修改 = 同步推送服务器，其它客户端也立即跟着变。

⚙ 大屏底色

5 类预设 + 1 类自定义：

  • 纯色：8 个色板 (深邃蓝 / 泳池青 / 深海蓝 / 森林绿 / 紫罗兰 / 暗紫红 / 炭墨黑 / 青灰)
  • 渐变：8 个层次感渐变
  • 高级混合：12 个深度感 mesh 底色
  • 灰度：8 档不同灰度
  • 图案：8 种横纹 / 格纹 / 光晕等
  • 自定义：颜色拾色器 + 16 进制 + 上传本地图片做底

字 大屏字号 (Font Scale)

全局缩放所有比赛内容字号 (0.8x ~ 3.0x, 步进 0.1)。

控件 / 快捷键动作
[−] 1.5x [+]点击调整, 数值实时显示
恢复 1.0x一键重置
Ctrl +字号 +0.1
Ctrl −字号 −0.1
Ctrl 0重置为 1.0x

颜色优先级（高 → 低）：

3. 用户自定义色 — 其他场景生效

七、远程样式控制（v2026.06.01 新增，重点）

核心设计：底色、字号、9 处文字配置由主服务器集中托管，持久化到 display_style.json。多个 display.html 共享同一套样式；任意控制端改动 → 服务器广播 → 所有 display.html / 控制端实时同步。服务器重启后样式自动恢复。

可控端（4 个）

端入口
display.html 自己右下角 ⚙ / 字 / 文 三按钮；本地改动也自动推送服务器
control.html
(显示模式控制网页)		底部新按钮"🎨 大屏样式 (底色 / 字号 / 文字)" → 弹出对话框
RemoteDisplayControl.exe
(远程显示控制 WPF)		底部新按钮"🎨 大屏样式" → 独立窗口
主控 PC
(SwimmingScoreboard.exe)		"比赛控制 → 显示控制"区块紫色按钮"🎨 大屏样式 (底色/字号/文字)" → 对话框

WebSocket 协议

方向类型说明
控制端 → 服务器SET_DISPLAY_STYLEdata: {bg?, fs?, textStyle?, textStyleMerge?}
控制端 → 服务器GET_DISPLAY_STYLE打开面板时拉取当前值
服务器 → 所有客户端DISPLAY_STYLE_PUSHdata: {bg, fs, textStyle}

textStyleMerge=true 表示局部合并（只更新指定字段）；false / 未设 表示完整替换。

典型用法

  • 场景 A: 操作员想把字号调大 → control.html → "🎨 大屏样式" → 字号 [+] → 大屏立即放大
  • 场景 B: 裁判长统一改比赛名称颜色为金色 → 主控 PC → 比赛控制 → 显示控制 → "🎨 大屏样式" → 文字样式 → 比赛名称改色 → 所有大屏同步
  • 场景 C: 远程统一改底色为极光蓝 → RemoteDisplayControl.exe → "🎨 大屏样式" → 底色填 linear-gradient → 所有大屏底色统一切换

八、断线重连

WebSocket 断开后 display.html 自动尝试重连。连续重连失败会弹出"连接主服务器"遮罩, 用户可重新输入 IP。重连成功后画面立即恢复, 不会丢任何数据（服务器重发 snapshot + 当前样式）。

九、常见问题排查

问题解决方案
LED 屏上字太小看不清右下角 字 → [+] 调到 2.0x ~ 3.0x，或 Ctrl +。更佳：用 control.html / 主控 PC / RemoteDisplayControl 远程统一调整。
字号调过头, 一行装不下Ctrl 0 一键回到 1.0x。
多个大屏样式不一致v2026.06.01 起样式由服务器集中托管, 应自动同步。检查各显示终端是否都连同一台服务器。
在 RemoteDisplayControl 改了字号, 大屏没反应确认两端都连接到服务器（绿色"已连接"）。服务器收到 SET_DISPLAY_STYLE 后会立即广播 DISPLAY_STYLE_PUSH。
计时复位后滚动时间还显示上组时间v2026.06.01 已修复。非比赛主视图下不再被硬件残留 0x7F 帧覆盖。
自动晋级确认后大屏闪烁v2026.06.01 已修复。display.html 忽略所有非 SHOW_* 的控制通知消息。
接力 "混合子" 错显v2026.06.01 已修复。混合性别显示为"混合"。
接力比赛只想看当前棒当前版本只支持 4 棒同列显示, 当前棒已经高亮金色。如需"只显当前棒"模式联系开发者。
用自己的图片做大屏底色⚙ → 自定义 → 图片 → 选择本地图片 → 自动转 base64 存 localStorage。图片不要超几 MB。
浏览器 Ctrl+/- 失效display.html 主动拦截这两个组合键用于字号缩放。这是设计行为。
