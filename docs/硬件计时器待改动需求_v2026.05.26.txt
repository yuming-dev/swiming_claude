  本次 PC 端发的 0x41 完整帧示例（用于硬件抓帧对照）
─────────────────────────────────────────────────────────────

  场景：用户 timing_settings.json 里 LaneCloseTime=10s, 终点 left,
        其它默认，进入 50 米项目后：

    StartPosition  = "right"
    FinishPosition = "left"
    LaneOrder      = "forward"
    sp50m          = 1   (StartPosition ≠ FinishPosition)
    StartPlace     = 1   (StartPosition == "right")
    LaneDir        = 0   (forward)
    placeDir (d8)  = (0<<4) | (1<<1) | 1 = 0x03

  完整帧 (12 字节，hex)：
    F1 53 41 0A 0A 05 05 00 03 03 03 F4
    └─SOH
       └─'S'
          └─CMD = 0x41
             └─d3 = 0x0A (ArmDelayNormalTime = 10s, 用户 LaneCloseTime)
                └─d4 = 0x0A (ArmDelayAfterStartTime = 10s)
                   └─d5 = 0x05 (MBDelayTime = 5s)
                      └─d6 = 0x05 (Result_Display_Time = 5s)
                         └─d7 = 0x00 (StartboxEdgeBit = 下降沿)
                            └─d8 = 0x03 ← sp50m=1, StartPlace=右
                               └─d9 = 0x03 (TPDelayTime = 3s)
                                  └─d10 = 0x03 (SBDelayTime = 3s)
                                     └─EOT

  如果硬件 UART log 里收到这帧但出发台仍开左端，
  100% 是固件 0x41 路径里 sp50m 没正确同步到主状态机的问题。
