成绩存盘路径

浏览器本机存盘配置 (保存到本机 localStorage). 由于浏览器沙箱限制, 无法直接写入绝对路径; 点击"打印成绩"时会通过浏览器下载机制保存到本机默认下载目录, 文件名按此处的命名格式生成.

热敏打印

浏览器本机打印配置. 点击"打印成绩"时按这里设置, 通过浏览器调起打印机 (Ctrl+P 同款). 主控 PC / RTC 的热敏打印是另一套配置, 互不影响.

用户名和密码

浏览器本机账号 (保存到 localStorage). 当前 race_control.html 连接服务器不验证账号, 此账号仅作本机操作员标识用 (写入比赛日志). 修改 PC 端 (主服务器 / RTC) 凭据请到对应机器的"参数设置"操作.

🖼️ 图片 / 视频

从浏览器本机选择文件, 上传到主服务器播放到大屏 (建议 < 16 MB). 支持: png / jpg / bmp / gif / webp / mp4 / webm / ogg / m4v

📊 PPT 播放

从浏览器本机选择 PPT 文件, 上传到主服务器. 主控 PC 用 PowerPoint COM 转 PNG 后, 通过 SHOW_MEDIA 通道把每张幻灯片推送到大屏, 翻页控制窗口在主控 PC 弹出. 支持: .ppt / .pptx (建议 < 32 MB)

左右盲表数量设置

每道使用的盲表数量（1-3）。修改后将通过服务器同步到所有计时控制台与硬件计时控制器。
