游泳计时系统 现场速查卡

v2026.09.14 · 贴在计时机旁边 · 详细说明见《使用说明书》

一场比赛，六步

动作 看什么
1 赛程导航点到这一组 中间出现本组名单
2 准备就绪 出发台打开，大屏切到本组
3 发令 滚动时间开始走
4 比赛中 触板/盲表自动记，需要就判罚
5 确认本组成绩 成绩锁定入库，大屏切组成绩
6 计时复位 进入下一组

判罚四个键

键 含义 还计时吗 有成绩吗 排名吗
DNS 没来 ✕ ✕ ✕
DNF 没游完 ✕ ✕ ✕
DSQ 犯规取消 ✕ ✕ ✕
TRI 试游 ✓ ✓ ✕
  • TRI 要计时：人下水、触板照记、成绩照出，只是不进名次、不计分、不算纪录
  • DSQ 接力会先问犯规棒次，前面几棒的分段保留
  • 判错了用取消备注撤销
  • 计时复位（抢跳重赛）清时间但保留备注

按错了「确认本组成绩」怎么办

确认一按就锁死：成绩、判罚、分组全改不了。

「解锁本组成绩」 —— 确认键正下方，琥珀色

  1. 第一道：弹窗看清是哪一组
  2. 第二道：手输组号 + 写原因（防手滑，必填）
  3. 改成绩 / 改判罚
  4. ⚠ 改完必须再点一次「确认本组成绩」
漏了第 4 步，改动不入库——过一会儿会自己变回旧值。

解锁会记进系统日志和竞赛库审计表（谁、几点、为什么）。

正在计时/已就位时不给解。只能在计时端这台解。

谁能发令：EXE > 网页 > 主服务器

优先级 谁 被压住时的表现
1 计时端程序（池边这台） 永远能用
2 比赛控制网页 计时按钮停用，顶部橙条
3 主服务器「比赛控制」页 页签变灰，点不进去
  • 高的一退出，低的自动恢复，不用重启
  • 切项目、切组次、显示控制不受影响，网页照常能用

比赛中能改别的项目

只有正在比的那一组锁着，别的项目、别的组随便改。动不得的只有四种: 正在计时/已就位、已完赛、成绩已录未确认、计时端正开着它 —— 界面会说清是哪一组、为什么。

出状况

现象 怎么办
改完过一会儿又变回去了 漏了最后那次「确认本组成绩」
判罚按钮没反应 这组已完赛 → 先「解锁本组成绩」
网页上按发令没反应 计时端程序在跑，网页让位 → 去计时端那台按
某道标了 DSQ 就不计时了 正常。要继续计时用「取消备注」撤销
大屏回不到比赛视图 按「比赛视图」即可；若无效，Ctrl+F5 刷新大屏
大屏页顶红条说版本不一致 Ctrl+F5；还不行说明那台的 Web\ 目录没更新
客户端全连不上 ① 防火墙放行 3002 / 8080 ② 是不是开了两个主服务器抢端口
硬件计时器一直红 串口号 / 波特率 / 接线 / 硬件电源
弹窗"竞赛库打不开" 缺 VC++ 运行库，用安装包重装一次
比赛中途程序崩了 重开、加载同一赛事 → 会弹窗问是否恢复上次进度

开机顺序

① 主服务器(记下顶栏 IP) → ② 计时端填该 IP 连接、再连硬件 → ③ 大屏浏览器开 http://该IP:8080/display.html 按 F11 → ④ 其它网页同理换文件名(race_control / query / register / checkin)。

主服务器 + 计时端的摆法, 主服务器用带 --role server 的快捷方式启动(自动摘掉「比赛控制」页)。

网页和主程序必须同版本一起换 —— 只换一半会出现"设备灯不刷新""日志不动"这类查不出原因的毛病, 页顶红条就是在提醒。
